# P001 — When multiplication is representable but hard to learn

**Status:** active · **Track:** theory → test design · **Prerequisite:** Chapters [1](../01-linear-parts-nonlinear-wholes.md) and [2](../02-representation-is-not-discovery.md) · **Deadline:** none

**Research purpose:** Before changing the model, decide what observation would separate a bad optimization path from missing representational capacity. This is not a quiz with a single approved explanation.

You may submit only one part. A counterexample or a correction to our assumptions is a useful outcome.

## Part A — Derive the learning signal (paper)

For `k ≥ 2`, take

\[
 f_\theta(x)=\prod_{i=1}^k(\theta_i^\top x),\quad
 L(\theta;x,y)=\tfrac12(f_\theta(x)-y)^2.
\]

1. Prove that `fθ(tx)=t^k fθ(x)` for any scalar `t`.
2. Derive `∇_{θ_j}L` for one operand `j` without assuming the operands are equal.
3. Set `θ_i=εv_i`, with bounded vectors `v_i, x` and nonzero target `y`. Find the leading order in `ε` of the gradient norm for `k=2` and `k=4`, away from degenerate factors. Does the same analysis hold if the target `y` also goes to zero with `ε`?
4. If every `θ_i=0`, is this a stationary point? Does its existence prove that gradient descent from a generic random initialization fails? Explain the logical gap.

**Check yourself:** You should find a product of the *other* `k−1` operand evaluations in the gradient. If your result depends only on `θ_j`, revisit the product rule.

## Part B — Challenge the explanation (research reasoning)

Select **two** competing hypotheses from Chapter 2, or invent a better one. For each, state one intervention that should help under that hypothesis and one observation that would count against it. Keep the synthetic quartic task, data split and operation budget fixed at first.

Examples of allowable *questions*, not endorsed solutions: Is layerwise initialization informative without giving the solution? Can forward-state normalization rescue a few outliers while hurting the model's ability to express products? Does more training data cure the gap while changing the optimization method does not?

Now name **one confounder** you would measure before interpreting the outcome.
